# MC Arquitecto Biblioteca

Base de conocimiento portable para conversaciones, decisiones, patrones, snippets y playbooks relacionados con Marketing Cloud.

## Objetivo

Tener una fuente de conocimiento propia, portable y versionada, independiente de una sola herramienta.

## Estructura

- `inbox/` - material pendiente de clasificar
- `raw-chats/` - exportaciones o transcripciones originales
- `summaries/` - resúmenes de conversaciones
- `decisions/` - decisiones técnicas y funcionales
- `patterns/` - patrones reutilizables
- `snippets/` - fragmentos de código y ejemplos
- `playbooks/` - guías paso a paso
- `indexes/` - índices temáticos y catálogos
- `templates/` - plantillas base
- `meta/` - normas, taxonomía y proceso

## Flujo recomendado

1. Añadir nuevos chats o exportaciones a `inbox/` o `raw-chats/`
2. Crear un resumen en `summaries/`
3. Extraer decisiones, snippets, patrones o playbooks si aplica
4. Actualizar índices
5. Mover o archivar el material ya procesado

## Convenciones

- Formato principal: Markdown
- Fechas en ISO: `YYYY-MM-DD`
- Nombres de archivo descriptivos y en kebab-case
- Añadir tags y fuentes cuando sea posible
