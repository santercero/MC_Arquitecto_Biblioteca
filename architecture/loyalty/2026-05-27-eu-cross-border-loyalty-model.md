# Qué es este documento

Resume el modelo funcional y arquitectónico asumido para operar un programa loyalty paneuropeo con niveles de status y beneficios compartidos entre países.

# Por qué importa

Afecta a CRM, loyalty backend, ecommerce, retail, customer care, reporting y Marketing Cloud. Es base de futuras decisiones de segmentación, journeys y sincronización.

# Qué conocimiento extraer

- Estructura de niveles `Classic`, `Premium`, `Prestige`, `Ambassador`
- Lógica cross-country de earn and burn
- Beneficios progresivos por tier
- Necesidad de sincronización coherente entre países y canales
