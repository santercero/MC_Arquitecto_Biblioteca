# Reglas de curación

## Etiquetas de evidencia

Cada nota relevante debería indicar una de estas bases:

- `official-doc`
- `community-confirmed`
- `observed-runtime`
- `inferred`
- `hypothesis`

## Campos mínimos recomendados

- título
- fecha
- fuente
- tags
- estado
- tipo de evidencia
- resumen
- riesgos o límites
- relación con otros documentos

## Reglas prácticas

- No elevar una nota a `canonical` si solo hay una fuente dudosa
- Marcar claramente lo no verificado
- Separar patrón general de caso concreto
- Guardar edge cases aunque parezcan raros si son reproducibles o costosos
- Documentar contradicciones entre documentación y comportamiento real
